# Mood-based-entertainment-picker
A simple and interactive web application that helps users discover entertainment based on their mood, preferred category, and ratings. Users can search for entertainment, filter and sort results, get random suggestions, save favorites, and track recently viewed items.

#Project Overview
  The Mood Entertainment Picker is a frontend web development project built using HTML, CSS, and JavaScript. It provides a simple interface for exploring different     types of entertainment, including movies, anime, games, and songs.
  Users can select their current mood, choose an entertainment category, search for specific titles, and sort items based on their ratings. The application also         includes favorites, recently viewed history, and a light/dark theme toggle.
  
#Features
  Search entertainment items by title.
  Case-insensitive search functionality.
  Display a message when no matching items are found.

#Mood-Based Filtering
  Filter entertainment based on the following moods:
    Happy
    Sad
    Relax
    Motivated
    Horror

#Category Filtering
  #Explore entertainment by category:
    Movies
    Anime
    Games
    Songs

#Rating-Based Sorting
  High Rating: Sort items from highest to lowest rating.
  Low Rating: Sort items from lowest to highest rating.

#Favorites
  Add entertainment items to your favorites list.
  Prevent duplicate favorites.
  Save favorite items using browser Local Storage.
  Display saved favorites after refreshing the page.

#Recently Viewed
  Add items to recently viewed history.
  Display the most recently viewed item first.
  Maintain a maximum of four recently viewed items.
  Save recent history using Local Storage.
